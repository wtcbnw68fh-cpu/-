# BizTalk · 변리사 비즈니스 영어 (iPhone 웹앱)

변리사 실무 영어 회화 연습용 앱. 운전 중 핸즈프리 회화, 지하철 리스닝·딕테이션, 영어 면접 대비를 지원합니다.
설치 없이 Safari에서 **홈 화면에 추가**하면 일반 앱처럼 실행되고 **오프라인**에서도 동작합니다.

## iPhone에 설치 (1회)
1. 이 저장소에서 GitHub Pages 켜기: **Settings → Pages → Source: Deploy from a branch → 브랜치 `claude/business-english-app-n0qd4r` / `/(root)` → Save**
2. 1~2분 후 iPhone Safari에서 `https://wtcbnw68fh-cpu.github.io/-/` 접속
3. 공유 버튼 ⬆︎ → **홈 화면에 추가**
4. 처음 실행 시 마이크·음성인식 권한 **허용** (설정 > 일반 > 키보드 > **받아쓰기** 켜져 있어야 함)

> 음성: 모든 영어·프랑스어 문장은 미리 생성된 AI 음성(Kokoro TTS, `audio/`)으로 재생. 문장을 추가·수정하면 `python3 tools/gen_audio.py --model … --voices …`로 다시 생성.

## 기능
| 기능 | 내용 |
|---|---|
| 🎤 스피킹 교정 | 짤 카드의 한국어 상황을 보고 영어로 말하기 → 단어별 비교(맞음/근접/누락), 점수, 정답 음성 |
| 💼 영어 면접 | 12개 빈출 질문(변리사 포지션) · 키워드·길이·말 속도·군말 피드백 · 모범답안 쉐도잉 |
| 🚗 오디오 모드 | 드라이브 회화(말하면 채점) / 쉐도잉 / 리스닝 루프 / 면접 리스닝 — 시작만 누르면 자동 진행, 화면 꺼짐 방지 |
| 🩺 실력 점검 | 레벨별 9문항으로 시작 레벨 배정 |
| 📈 점수화 | BizTalk Score(0~1000) 일별 그래프, 영역별 정확도 |
| ⬆️ 자동 난이도 | 현재 레벨 최근 20회 평균 85점 이상(15회 이상) → 자동 승급 |
| 🏅 보상 | XP, 직급(Intern→Managing Partner), 하루 목표, 연속 학습일, 배지 12종, 축하 효과 |
| 🖼️ 내 짤 넣기 | 표현 카드에 사진첩의 밈 이미지를 직접 붙이기 (기기에만 저장) |
| 🔁 간격 반복 | 자주 쓰는 표현부터 출제, 틀린 표현은 10분 뒤/맞힌 표현은 1·3·7·14·30·60일 뒤 복습 |

## 오류로 시간 낭비하지 않도록
- 음성인식 실패/권한 없음 → 자동으로 **입력 모드**로 전환, 드라이브 모드는 **쉐도잉**으로 자동 전환
- 축약형(I'll = I will), 숫자(3 = three), 대소문자·문장부호 차이는 오답 처리하지 않음
- 모든 데이터는 기기 안(localStorage)에만 저장, 설정에서 백업/복원 가능
